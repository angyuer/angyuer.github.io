# Projects Page Override

## Purpose

Present project work as scannable case studies rather than a generic article archive.
The page must expose current status, period, role, stack, links, and the latest update
without requiring the visitor to open every article.

## Layout

- Start with an unframed editorial header and a compact project count summary.
- Use one full-width project card per case study until there are at least four projects.
- Keep the project image and project facts at the same hierarchy; do not place cards
  inside the project card.
- On mobile, stack the image above the content and keep primary links at least 44px tall.

## Material

- Reuse the global pearl and graphite surfaces, 26px card radius, and 190ms motion.
- Status uses text plus a small warm neutral dot; never communicate state by color alone.
- Do not adopt blue selected states, masonry, long fluid animations, or unrelated portfolio
  decoration suggested by generic portfolio patterns.
